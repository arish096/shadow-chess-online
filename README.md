## 🚀 Live Demo

**Play here:** https://shadow-chess-online.onrender.com

Open the live game, create a room, and invite another player using the room code. You can also play against the computer AI.

> **Note:** The free hosting service may take a little time to wake up after inactivity.

## ✨ Features

- ♟️ **Online Multiplayer** — Create rooms and play with friends using room codes.
- 🤖 **Computer AI** — Challenge a computer-controlled opponent.
- ⚖️ **Chess Rules** — Legal move validation and checkmate detection.
- 🔄 **Real-Time Gameplay** — Synchronize moves between connected players.
- 👑 **Promotion & Special Moves** — Support for chess mechanics implemented in the game.
- 🏁 **Game Controls** — Includes game actions such as resigning, offering a draw, and starting a new game.
- 🎨 **Dark Gaming UI** — A modern interface designed for a focused chess experience.
- 📱 **Responsive Design** — Play through a browser on desktop or mobile.

## ⚙️ Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) installed
- Git installed
- A web browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/arish096/shadow-chess-online.git
```

**2. Open the project directory**

```bash
cd shadow-chess-online
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the server**

```bash
npm start
```

**5. Open the game**

Visit:

```text
http://localhost:3000
```

If you configured a different port, open the corresponding local URL.

## 🎮 How to Play

1. Open the live demo or run the project locally.
2. Choose the computer opponent or create a multiplayer room.
3. For multiplayer, share the room code with your friend.
4. Join the same room from another browser or device.
5. Make your moves and enjoy the game!

## 🌐 Deployment

The application is deployed on Render.

- **Live application:** https://shadow-chess-online.onrender.com
- **Repository:** https://github.com/arish096/shadow-chess-online

The application requires a Node.js hosting environment that supports WebSocket connections for multiplayer functionality. GitHub Pages alone cannot host the Node.js server.
